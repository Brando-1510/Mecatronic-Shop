
NODEX

#Descripción general
Nodex es una tienda web conceptual enfocada en la venta de componentes electrónicos y eléctricos para proyectos de robótica, electrónica, mecatrónica y automatización.

El proyecto no se plantea como una tienda genérica, sino como una tienda-asistente técnico, donde el usuario puede buscar productos por categoría, parámetros técnicos, compatibilidad o tipo de proyecto.


#Objetivo
Diseñar y desarrollar una plataforma web clara, moderna y funcional que permita explorar, comparar y seleccionar componentes electrónicos y eléctricos de forma técnica, ordenada y orientada a proyectos reales.


#Público objetivo
    -Estudiantes de ingeniería.
    -Técnicos electrónicos y eléctricos.
    -Makers.
    -Personas que desarrollan proyectos de robótica.
    -Usuarios que trabajan con Arduino, ESP32, sensores, motores, fuentes y módulos electrónicos.
    -Docentes o personas que necesitan armar listas de materiales para proyectos.


#Problema que resuelve
Muchas tiendas de electrónica muestran productos sin suficiente información técnica, filtros útiles o advertencias de compatibilidad.

Este proyecto busca resolver ese problema mediante una estructura que permita:

    -Buscar componentes por datos técnicos.
    -Identificar productos compatibles.
    -Evitar errores comunes de conexión.
    -Comprar por proyecto.
    -Consultar especificaciones claras.
    -Recibir recomendaciones técnicas dentro del flujo de compra.
    -Funcionalidades principales
    -Landing page principal con estructura comercial y técnica.
    -Catálogo de productos.
    -Búsqueda técnica por parámetros.
    -Filtros por categoría, voltaje, corriente, aplicación y compatibilidad.
    -Cards de productos con información técnica relevante.
    -Página individual de producto.
    -Especificaciones técnicas del producto.
    -Compatibilidad y advertencias de uso.
    -Carrito de compra.
    -Control de cantidades.
    -Eliminación de productos del carrito.
    -Subtotal y total.
    -Recomendaciones técnicas.
    -Advertencias de compatibilidad.
    -Kits/BOM recomendados.
    -Compra por proyecto.
    -Comparador técnico básico.
    -Sección de guías y soporte.


#Tecnologías usadas
    HTML5.
    CSS3.
    JavaScript.
    LocalStorage para persistencia básica del carrito.
    Git y GitHub para control de versiones.
    Diseño responsive para escritorio, tablet y móvil.



#Cómo ejecutar el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el proyecto con la extensión Live Server.
4. Abrir index.html en el navegador.


#Navegar entre las páginas principales:
    index.html
    pages/catalogo.html
    pages/producto.html
    pages/carrito.html
